# Trellis

> Trellis (Trellis Research) is an AI-powered state and federal trial court research and litigation analytics platform. It makes the fragmented U.S. state trial court system — plus federal, appellate, supreme, and bankruptcy courts via PACER — searchable through a single interface, and exposes that data programmatically through the Trellis Trial Court Data API for case research, business development, due diligence, and lead generation.

## About
- Company: Trellis Research, Inc. (trellis.law), Los Angeles, CA
- Founder/CEO: Nicole Clark (co-founder Alon Shwartz)
- Focus: legal analytics, state + federal trial court data, litigation intelligence
- Access model: sales-gated free trial (contact sales@trellis.law)

## API
- Trellis Trial Court Data API — https://trellis.law/legal-data-api
  - Current version: V2 (May 2024), adds federal + PACER on top of V1 state coverage
  - Coverage: State Trial, Federal, Appellate, Supreme Court, and Bankruptcy cases
  - Capabilities: Smart Search (rulings/dockets/documents), Docket / Case Data (parties, attorneys, documents, events), Docket Refresh, Rulings, Documents, Judges analytics, Alerts, Usage, Webhooks
  - Authentication: issued API-key credentials (provisioned at onboarding)
